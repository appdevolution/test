# Typewriter Android

App Android nativa in Kotlin che simula una macchina da scrivere.

## V1
- Editor full screen senza WebView
- Carta crema, bianca, invecchiata e notturna
- Suoni meccanici differenti per tasti, spazio, backspace, ritorno carrello e campanella
- Micro movimento del foglio e feedback aptico
- Autosalvataggio locale
- Importazione ed esportazione TXT con Storage Access Framework
- Conteggio parole e caratteri
- Modalità Focus
- Font inclusi: Courier Prime, Special Elite, EB Garamond, Libre Baskerville
- Supporto per importazione locale di Minion Pro in formato OTF/TTF

Il file Minion Pro non viene pubblicato nel repository. L'app consente all'utente di importare la propria copia licenziata.
